# Icy Punishing（冰洁·惩击）

[English](README_EN.md) | 简体中文

> 以《战双帕弥什》为灵感的 NeoForge 战斗向模组：意识套装、武器、信号球三消与角色专属技能组。

A NeoForge 1.21.1 combat mod inspired by *Punishing: Gray Raven* — awareness set bonuses, signal-orb combos, katanas and character skill sets.

## 模组简介

**Icy Punishing** 将《战双帕弥什》的核心战斗语言带进 Minecraft：装备 6 件「意识」凑出套装效果，切换战斗姿态，用红/黄/蓝三色**信号球**消球放技能，攒满能量释放**必杀**，并通过升阶、跃升、突破与强化把武器和角色养成到极限。

不同太刀对应不同的**角色技能组**，主手武器决定你当前使用的角色。

当前包含：

- **30 套意识、共 180 件**，每套都有 2/4/6 件套装效果；
- **16 把可用太刀** + 6 种外观涂层、**6 把弓** + 7 种外观涂层；
- 3 个完整角色技能组：**红莲**、**影打-逆断**、**红樱**；
- 刀光扫击、超算空间、浮游刃随从；
- 完整的武器突破 / 强化 / 跃升与意识强化 / 回收体系。

## 安装

1. 安装 Java 21 与 NeoForge 21.1.235（或兼容的 1.21.1 版本）；
2. 从 [Releases](https://github.com/icylemonheart/icy_punishing/releases) 下载 `icy_punishing-1.1.0.jar`，并准备 Icy Lib 1.1.2+ 与 Curios API；
3. 将 jar 放入客户端的 `mods` 文件夹；联机时服务端也需要安装；
4. 可选：安装「更多锻造模板」，武器制作配方会用到其中的材料。

## 游玩

1. 攻击敌人积攒信号球与能量；
2. 按数字键 `1`～`8` 消除信号球释放技能，**三消**会触发强化版技能；
3. 能量满后按 `X` 释放必杀；
4. 使用道具「人类屹立于此」打开强化界面，进行升级、晋升、武器突破与意识强化。

### 默认按键

| 按键 | 功能 |
| --- | --- |
| `Z` | 切换战斗 / 收刀姿态 |
| `X` | 释放必杀技 |
| `1`～`8` | 消除对应位置的信号球并释放技能 |

> 按键可在「选项 → 控制」中重新绑定。

## 意识系统

### 基本规则

- 意识装备在 Curios 的 6 个专属槽位（`awareness_1`～`awareness_6`）；
- 每件意识提供生命、会心、攻击、防御四项数值，各自带随机区间；
- 品质越高，数值越高（2★ 约 50～80 生命，6★ 可达 145+ 生命、130+ 攻击）；
- 同一套装装备 2 / 4 / 6 件时分别激活对应套装效果；
- 意识可强化（消耗意识强化素材），也可回收换取材料。

## 战斗机制

### 信号球

- 攻击命中回复信号球与能量；消球额外回复能量；
- 球分红、黄、蓝三色，1～8 号位随机分布；
- 相邻同色可一次消除多颗，消 3 颗即「三消」，触发强化技能；
- 不同角色的三消收益与触发条件不同。

### 刀光扫击

挥砍会以武器模型碰撞判定命中：刀身长度 3 格、半径 0.35 格、约 120° 扇形范围内的敌人会受到伤害。

### 超算空间

特定条件（完美闪避、套装效果）会触发超算空间：画面进入滤镜状态，周围敌人大幅减速，是输出与走位的核心窗口。

### 浮游刃

装备「天狼星」时，副手会生成浮游刃，自动攻击 12 格内的敌人，每秒 1 次，并优先攻击上一次的目标。

## 掉落与获取

- 意识由怪物按最大生命分档掉落，可在配置中调整概率；
- 经验仓、螺母包、技能点按里程碑掉落；
- 武器与突破材料通过配方合成，配方覆盖基础刀、高阶刀、突破核心与回收。

## 常见问题

**Q：为什么按技能键没有反应？**
A：技能组需要主手持有对应的太刀，并且处于战斗姿态（按 `Z` 切换）。空手或持其它武器不会触发。

**Q：信号球不显示 / 技能图标不出现？**
A：请确认已装配 Icy Lib 与 Curios，并且主手武器属于本模组。

**Q：为什么伤害数字很低？**
A：本模组采用前置库的「抗性除法 + 防御减法」结算方式，怪物默认带有基于最大生命的防御。可通过 Icy Lib 配置降低怪物防御倍率，或通过意识、强化提升攻击与穿透。

**Q：套装效果为什么只亮了一部分？**
A：套装按 2 / 4 / 6 件激活，部分套装本身只有 2/4 件套；另外腓特烈套装的 2/4 件效果尚未实现。

**Q：FancyText 的彩色 / 闪烁文字是什么？**
A：这是 Icy Lib 提供的富文本样式，属于正常显示。

**Q：可以只装在服务端吗？**
A：不可以。本模组包含 HUD、特效与按键，客户端与服务端都必须安装。

- 必须安装 Curios 与 Icy Lib；可选的「更多锻造模板」用于武器材料配方；
- 与其它减伤 / 护甲模组共存时，注意伤害结算顺序；
- 武器使用 OBJ 模型，低配光影下若出现模型异常，可尝试切换渲染设置。

## 构建（开发者）

需要 JDK 21。项目通过 `flatDir` 引用同级目录下的前置库产物，直接克隆本仓库需先构建 icy_lib：

1. 将 icy_lib 源码放在与本项目同级的 `icy_lib-NeoForge-1.21.1` 目录并执行 `gradlew build`；
2. 在本项目执行 `gradlew build`；
3. 产物位于 `build/libs/icy_punishing-1.1.0.jar`。
